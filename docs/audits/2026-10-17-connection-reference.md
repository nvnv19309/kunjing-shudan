# 孤独表达、首页目录入口与专业阅读扩充

## 本轮决定

“我感觉没人爱我”在原版确实未命中；“没人喜欢我”“没有人关心我”“我不值得被爱”也缺少入口。这是关键词与主题覆盖问题，不等于没有可读的书。

新增“孤独与被爱感”主题，归入关系与边界，追加到原16主题之后。依次使用《也许你该找个人聊聊》《静观自我关怀》《自尊》《亲密关系》，补充面向孤独、联结与自我评价的专属推荐理由，不新增自助作品或引入诊断专项书。孤独表达本身不触发人格障碍书单；其他主题已有求助和诊断提醒规则保留。

新主题含24个关键词；“孤独”从人际主题、“不被爱”从家庭主题移入，净增22词。17主题、446关键词、76条日常推荐、6预警主题。未更改计分、去冗余、最长词或并列规则。复杂否定、反问等仍不属于朴素关键词算法的可靠能力范围。

首页“先逛书单”改为浅绿底、深绿边线的48px起步次级按钮，手机模拟窄屏宽度铺满输入区；困境输入仍是主入口。仅增加视觉样式，不改变目录事件或记录方式。

经用户选择，专业入口既整合现有教材，也新增作品。现有四部教材仍在原日常主题中；专业入口使用共享书籍ID，不复制封面、版本、评分或介绍。
