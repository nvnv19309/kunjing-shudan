# 推荐理由改写与验收记录

日期：2026-10-23。

## 问题与改写范围

原推荐常以“可以借它看看”“给感受留一点空间”“按问题挑选章节”等表达结束，缺少书与读者处境的联系。另有对象含糊、搭配生硬、同一理由跨主题复用的情况。

本轮重写64条目录理由和85条主题理由，共149条。每条说明适合什么处境，以及该书的内容、方法或论述视角为什么与这种需要相关；通常约70—90字。避免用笼统赞美代替理由，也不承诺改变或治疗效果。

同一本书在多个主题下分别写关联。例如《亲密关系》在关系去留、失恋和孤独主题中，分别说明互动模式、关系变化及亲近需求的阅读价值。面向日常读者的小说提供故事参照；教材说明理论和研究用途；临床参考仍明确专业学习、课程或督导需求。

## 内容依据与边界

依据已保存的所选版本介绍、目录与出版核对记录，以及现有summary和caveat改写。未新增版本、作者、页码、研究结论或疗效主张，不声称本轮逐本通读或经过专家审校。

书籍原有简介、阅读局限、诊断标注和求助提醒保留。BPD亲友读物写明适读对象，专业手册不包装成普通自助读物。小说和哲学的阅读价值不作为治疗证据。

## 数据与验证

- 仅修改books-data.js中的149个reason字符串，其他文本与结构按去除reason值后的原文件精确比对。17主题、64作品、85条日常引用、446关键词、书籍顺序、版本及评分均不变。
- 数据与算法回归通过；旧冻结断言仅豁免本轮获准改写的reason字段，仍保留其余书目、主题、排序、日志及190项目录检查。
- 13组浏览器功能检查通过，覆盖主题纠正、排序、目录、专业书架、滑动、导读、历史与返回状态。旧情绪文案字面断言改为验证主题理由与目录理由不同，并验证切换主题后理由随之改变，相关组重跑通过。
- 新增显示检查核对全部85条主题理由和两种目录分区，确认实际书卡使用当前主题的理由，文字可见、完整，输入和详情状态正常。
- 360×800、390×844、430×932共474个默认手机模拟书卡状态均无溢出、裁字且在一屏内，最大709.19px。详情展开及大字允许自然增高。
- Edge/Chrome、三种最小字号、两种字体栈和七种屏宽共84组布局及200% CSS缩放通过。手机硬件、Firefox、Safari及实际读屏听读未测试。

更新数据资源的缓存标识，并同步本地预览。发布只涉及推荐数据、页面资源版本与公开维护记录，不上传原始书籍、内部逐条审阅底稿或测试资料。
